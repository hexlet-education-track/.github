## Как работать с репозиторием

1. Найди в каталоге свой курс и нужное задание.
2. Создай свою копию репозитория:
   - **Use this template** — если репозиторий помечен в каталоге как шаблон;
   - **Fork** — во всех остальных случаях.
3. Склонируй свою копию и выполняй задание в ней.
4. Порядок сдачи описан в README конкретного репозитория.

> [!TIP]
> **Fork** сохраняет связь с исходным репозиторием: через него удобно отправлять Pull Request и подтягивать обновления задания. **Template** создаёт независимую копию с чистой историей — подходит, когда работа должна начинаться с нуля.
